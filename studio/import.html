Import a spreadsheet into your Private tier

M1 d. In Google Sheets choose File → Download → Microsoft Excel (.xlsx), then pick the file here. The file is read in this browser; only the rows you choose are sent, in checked batches of 200, to your Private tier (encrypted, never the shared record). Running it again is safe: rows already there are counted as repeats. An edited row is kept as a new version next to the old one, and every import leaves a manifest and a snapshot so any past state can be rebuilt.
